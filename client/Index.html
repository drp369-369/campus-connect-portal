│   └── package.json

└── README.md

Terminal Setup Commands
# 1. Create root directory
mkdir campus-connect-portal
cd campus-connect-portal

# 2. Initialize Root Git Repository
git init

# 3. Create Backend setup
mkdir server && cd server
npm init -y
npm install express mongoose dotenv cors jsonwebtoken bcryptjs
npm install --save-dev nodemon
cd ..

# 4. Create Frontend setup (React + Vite)
npm create vite@latest client -- --template react
cd client
npm install axios react-router-dom
cd ..

Phase 1: Create the Project Structure in VS Code
Open VS Code, press Ctrl + ~ (or Cmd + ~ on Mac) to open the integrated terminal, and follow these steps.
1. Create and Open the Project Root Directory
mkdir campus-connect-portal
cd campus-connect-portal
code . -r
2. Set Up the Express Backend (server) Run these commands in the terminal: 
# Create server folder and enter it
mkdir server
cd server

# Initialize Node project
npm init -y

# Create sub-folders
mkdir src src/config src/controllers src/models src/routes src/middleware

# Create starter files
touch src/config/db.js src/app.js .env.example
cd ..
3. Set Up the React Frontend (client) using Vite Run these commands to generate the React app and structure: 
# Create React app using Vite
npm create vite@latest client -- --template react

# Move into client folder
cd client

# Install basic dependencies
npm install axios react-router-dom

# Create internal folder structure
mkdir src/components src/pages src/context src/services
touch .env.example
cd ..
4. Create Root-Level Files Run this from the root directory (campus-connect-portal): 
touch README.md .gitignore
Paste the following content inside your root .gitignore file so node_modules and secret files are not uploaded: 
node_modules/
.env
dist/
build/
.DS_Store

Phase 2: Connect the Project to GitHub
1. Initialize Git Locally Run this command in the VS Code terminal at the root level (campus-connect-portal):
git init
2. Create a Remote Repository on GitHub
Go to GitHub.com and click the + icon in the top-right corner -> New repository.
Name the repository campus-connect-portal.
Leave "Add a README file" and "Add .gitignore" UNCHECKED (since you already created them locally).
Click Create repository.
Copy the HTTPS or SSH repository URL provided (e.g., https://github.com/your-username/campus-connect-portal.git).
3. Link Local VS Code Project to GitHub Back in your VS Code terminal, run the following commands (replace the URL with your own): 
# Add all files to staging
git add .

# Commit files locally
git commit -m "Initial commit: Setup project folder structure for client and server"

# Set branch to main
git branch -M main

# Link remote repository
git remote add origin https://github.com/your-username/campus-connect-portal.git

Verify and Push
1. Check if origin is added correctly:
git remote -v
You should see two lines displaying your GitHub URL for fetch and push.
2. Push your code
git push -u origin main
