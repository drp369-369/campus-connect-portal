# Campus Connect Portal

A unified platform connecting students, faculty, and administrators.

## Project Structure

- **`client/`**: React + Vite frontend application.
- **`Server/`**: Express & Node.js backend server.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Backend Setup

```bash
cd Server
npm install
npm run dev # or npm start
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```
